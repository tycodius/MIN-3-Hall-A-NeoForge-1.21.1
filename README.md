# MIN-3 Hall-A — NeoForge 1.21.1

Unofficial NeoForge port of [MIN-3 Hall-A](https://www.curseforge.com/minecraft/mc-mods/min-3-hall-a), originally made for Minecraft 1.20.1 Forge.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.x
- Java 21

## Features

- Drink Mixer and Shaker Pot
- Ferment Barrel
- BTC Filling Machine
- Drink recipes and effects
- Wandering Trader offers
- JEI recipes and obtaining information

## Building

Use JDK 21. From the project folder, run:

```powershell
.\gradlew.bat build
```

The JAR will be in `build/libs/`. The game has launched successfully in a NeoForge 1.21.1 client; dedicated-server compatibility and all recipes should be tested before wider distribution.
